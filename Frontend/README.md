# Frontend

Sitio estático del proyecto Método Judicial. Mantiene la estructura de carpetas que esperan los enlaces relativos de HTML, CSS y JavaScript.

En Windows, hacé doble clic en `Iniciar-Metodo-Judicial.bat`. Se abre la página en `http://127.0.0.1:8765/` y una ventana del servidor local. Cerrá la ventana del servidor para detenerlo. Requiere Python 3.

El campus, la biblioteca y el panel administrativo son una demostración con almacenamiento en el navegador. La integración de servidor está descrita en `../Backend/README.md`.
